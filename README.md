# School & Work

Life OSと連携する学校・バイト管理アプリです。

## 概要

School & Work は Life OS のサブアプリです。

学校の時間割・課題・テスト管理と、
アルバイトのシフト・給料管理を行います。

登録したデータは Firebase を通して
Life OS と自動同期されます。

## 主な機能

- 時間割管理
- 課題管理
- テスト管理
- シフト管理
- 給料自動計算
- Firebase同期

## 使用技術

- React
- TypeScript
- Vite
- Firebase
- Firestore
- Tailwind CSS
